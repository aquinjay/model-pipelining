# References

These are optional background and mathematical sources. The workflow/model/uncertainty guides explain the current tooling without requiring readers to work through these publications first. The sources do not prescribe this project's adapter API or release policy.

- Gelman et al., [Bayesian workflow](https://arxiv.org/abs/2011.01808), 2020 v1: model construction, simulation, computation, predictive checking, comparison, and iteration. The workflow also recognizes the importance of design and measurement outside the paper's main data-analysis scope.
- Hyndman and Athanasopoulos, [Forecasting: Principles and Practice — The forecaster's toolbox](https://otexts.com/fpp3/toolbox.html): benchmarks, forecast evaluation, uncertainty, and rolling-origin cross-validation.
- Särkkä, [Bayesian Filtering and Smoothing](https://users.aalto.fi/~ssarkka/pub/cup_book_online_20131111.pdf), 2013, Section 4.3: exact Gaussian filtering and the scalar Gaussian-random-walk example. The [local-level implementation](local-level.md) specifies its own initial-prior timing explicitly.
- [statsmodels unobserved-components documentation](https://www.statsmodels.org/stable/generated/statsmodels.tsa.statespace.structural.UnobservedComponents.html): the local-level observation and state specification. statsmodels is a reference, not a project dependency; the current filter uses fixed variances and the standard library.
- Hyndman, [Computing and graphing highest density regions](https://robjhyndman.com/papers/hdrgraph.pdf), 1996: density-based regions, including disconnected sets for multimodal laws. The [shared uncertainty contract](uncertainty.md) preserves segment structure and prioritizes supplied highest-density regions in reporting.
- Hyndman and Athanasopoulos, [Evaluating distributional forecast accuracy](https://otexts.com/fpp3/toolbox.html#evaluating-distributional-forecast-accuracy): quantile and Winkler interval scores. This implementation explicitly uses unscaled pinball loss and applies the interval score to equal-tail bounds only.
- [Python 3.14 NormalDist](https://docs.python.org/3.14/library/statistics.html#statistics.NormalDist): the adapter's standard-library normal quantile calculation. The shared runner does not assume a normal predictive law.
- [Stan posterior predictive sampling](https://mc-stan.org/docs/stan-users-guide/posterior-prediction.html): parameter integration and paired parameter/future-observation simulation, used in the [unknown-mean reference audit](parameter-uncertainty.md). Stan is background, not an installed backend.
- [Stan prior and posterior predictive checks](https://mc-stan.org/docs/stan-users-guide/posterior-predictive-checks.html): whole-dataset replication, descriptive discrepancies and prior implications, used by [the separate checking workflow](predictive-checks.md). Its draws are direct exact joint draws, with human interpretation and no automated discrepancy threshold.
- [Stan posterior analysis](https://mc-stan.org/docs/reference-manual/analysis.html) and [diagnostic warnings](https://mc-stan.org/learn-stan/diagnostics-warnings.html): finite-chain diagnostics, effective sample sizes, Monte Carlo precision, and HMC-specific problems. The implemented Metropolis audit retains applicable diagnostics and marks HMC evidence inapplicable; there is no release policy.
- [emcee moves](https://emcee.readthedocs.io/en/stable/user/moves/#metropolis-hastings-moves) and [sampler state](https://emcee.readthedocs.io/en/stable/user/sampler/): the maintained Gaussian Metropolis proposal, saved chain/log targets, and explicit random states. This project runs independent one-walker Metropolis samplers, not interacting walkers treated as independent chains.
- ArviZ 0.23 [rank R-hat](https://python.arviz.org/en/v0.23.0/api/generated/arviz.rhat.html), [ESS](https://python.arviz.org/en/v0.23.0/api/generated/arviz.ess.html), and [MCSE](https://python.arviz.org/en/v0.23.0/api/generated/arviz.mcse.html): the exercised pre-1.0 diagnostic API and chain/draw conventions.

- Murphy, [Conjugate Bayesian analysis of the Gaussian distribution](https://www.cs.ubc.ca/~murphyk/Papers/bayesGauss.pdf), 2007, Sections 5.5 and 6: normal/inverse-gamma updates and Student-t prediction used in [joint mean/variance learning](normal-mean-variance.md).
- The same conjugate calculations support [prior influence comparisons](prior-influence.md): changes to conditional mean precision and inverse-gamma shape/scale are evaluated exactly. The saved prior-location coefficient is conditional; scale decomposition and predictive differences expose other effects without an influence threshold.
- SciPy [normal/inverse-gamma](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.normal_inverse_gamma.html), [inverse-gamma](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.invgamma.html), and [Student-t](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.t.html): distribution parameterizations and reference density/quantile functions. Production joint forecasts use Student-t functions; independent tests also use raw likelihood quadrature and joint-density ratios.

Additional readings on experimental design and causal inference can be added when those questions become active. The current example's intended claim and evaluation limits are stated in [the walkthrough](forecasting.md#understand-the-example).
